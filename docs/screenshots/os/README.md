# Camera Bridge OS screenshots

Taken on 2026-10-22 from a real Camera Bridge OS box (beta 0.1.114, Beelink Mini S, Intel N150) with real cameras.
They are 2880 × 1800 JPEGs (a 1440 × 900 window at 2×) in the dark appearance. Network addresses, the Wi-Fi name and the API
key's last characters were replaced with placeholders before the capture.

Each file keeps its name across updates, so a website can link to it and get the newest picture:
`https://raw.githubusercontent.com/coalsi/camera-bridge/main/docs/screenshots/os/<file>`

| File | What it shows |
|---|---|
| `monitor.jpg` | The Monitor: every camera live in a grid, with the recordings timeline and the events list (with AI descriptions). A turned-off camera shows as such. |
| `events.jpg` | The Events page: every camera's events, newest first, each with a picture, its type and the AI's sentence, with filters by camera, type and what the AI saw. |
| `camera.jpg` | One camera's page: live preview, status, Record, and its Security card. |
| `security.jpg` | A camera's Security card: what Camera Bridge checked, and the Internet guard watching the camera's lookups. |
| `cameras.jpg` | The Cameras list: status, security, video, recording, events and Apple Home for each camera. |
| `notifications.jpg` | The Notifications page: everything that was a notification, with filters (here, the Internet guard blocking cameras' first tries). |
| `settings.jpg` | Settings: the bridge's name, password, time zone, video label and recording. |
| `ai-settings.jpg` | Settings › AI descriptions: the service (Claude or OpenAI-compatible), model, daily limit and the saved key. |
| `system.jpg` | System: the box, Wi-Fi, SSH, updates, the recording drive and restart. |
