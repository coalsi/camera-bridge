# iOS and CarPlay app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A universal iOS 27 app in Liquid Glass with everything the TV app does, plus Events, AirPlay and a CarPlay video scene.

**Architecture:** `ios/` is a new XcodeGen project whose target shares `apple-tv/App/Sources` through source paths, minus the nine remote-only views, and links the Kit at `apple-tv/Kit`. New logic goes in the Kit with tests; touch views go in `ios/App/Sources`.

**Tech Stack:** Swift 6, SwiftUI, AVFoundation, AVKit, CarPlay, XcodeGen 2.43, Swift Testing.

**Spec:** docs/superpowers/specs/2026-11-06-ios-carplay-app-design.md. All in `.superpowers/ios-map/` in the worktree, git-ignored: reuse map `tv-reuse.md`, CarPlay map `carplay-api.md`, glass guidance `ios27_design.md`, the throwaway test app `carplay-spike/`.

## Global Constraints

- Worktree `.claude/worktrees/ios-app`, branch `ios-app` (TV app plus main). Never commit to main, push, or publish.
- iOS 27.0 target. Bundle `com.coreysilvia.CameraBridgeiOS`, team `XL4RAH5J96`, name Camera Bridge. `SWIFT_DEFAULT_ACTOR_ISOLATION: MainActor`, approachable concurrency and `MemberImportVisibility` as the TV project.
- The TV app must keep building unchanged in behaviour: after any task touching shared files, build tvOS Debug on the simulator and check `swift test` in `apple-tv/Kit` (1050 tests or more, all pass).
- The Kit has no platform imports and no dependencies.
- Simulators: only ones you create (`xcrun simctl create`), deleted after. Every launch carries a `-CB…` argument. Never contact the owner's box. Dev daemon on loopback only. Never install on a real device.
- Signing: Simulator builds only. No `-allowProvisioningUpdates`, nothing on Apple's portal.
- No LAN addresses, device IDs, /Users/ paths, e-mail addresses or box labels in committed files.
- Text is plain and in `ios/App/Sources/Common` or the shared `Copy.swift`. CarPlay text never says to touch the iPhone.
- Commit messages: one plain sentence saying what a person gets, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Phone on a stranger's Wi-Fi with the same private range as home: no request carrying the key goes out.
2. Rotation or iPad resize in the middle of a live page: tiles redraw, one live request per page, no leaked session.
3. App in background then back, with a call or Siri in between: live resumes, sound state stays, no double session.
4. CarPlay scene connects while the phone is locked and no phone scene exists: the model starts, lists fill, and failure text shows, no crash.
5. Finger scrub past the ends of the window or over a gap in recordings: the picture and clock stay consistent; lifting seeks once.
